# Home Assistant App: NFS Server (Ganesha)

Expose Home Assistant folders via NFS (Network File System) using nfs-ganesha.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

## About

This app runs nfs-ganesha to share Home Assistant directories over your network using NFSv4.

## Features

- Select which folders to export
- IP-based access control
- Support for multiple authorized IPs/subnets
- Full read-write access
- NFSv4 support
